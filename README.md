# CookingMama

Многостраничный адаптивный сайт рецептов на Bootstrap 5. На страницах категорий и общего
каталога есть поиск и фильтры по кухне и главному ингредиенту. Для каждого блюда
открывается отдельная карточка с ингредиентами, пересчётом порций, шагами приготовления
и отзывами.

## Запуск

Откройте `index.html` в браузере или запустите каталог через локальный сервер.

## Страницы

- `index.html` — главная с подборкой популярных рецептов и ссылками на категории.
- `recipes.html` — каталог всех рецептов с сортировкой и фильтрами.
- `breakfasts.html` — завтраки.
- `main-dishes.html` — главные блюда.
- `desserts.html` — десерты.
- `recipe.html?id=pasta` — отдельная карточка блюда. Значение `id` соответствует идентификатору рецепта в данных.

## Возможности

- Закреплённая при прокрутке навигационная шапка и подвал на всех страницах.
- Sticky-блок фильтров на главной, в каталоге и на страницах категорий.
- Фильтры по стране кухни и основному ингредиенту, текстовый поиск и сортировка.
- Пересчёт ингредиентов при изменении количества порций.
- Отзывы сохраняются в `localStorage` браузера.
- Адаптивная вёрстка на Bootstrap.
- Фотографии рецептов загружаются из `images` и показываются целиком в карточках.
